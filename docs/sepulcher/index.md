# :material-coffin: Sepulcher

The **Sepulcher** is LychD's rootless runtime body: the services, mounts, and execution topology
that house its organs on a Linux host. Read this map when your question is **which part owns this?**
It points to the smallest chamber that can answer; each child page owns its operation and detail.

The **Lich** is the recurrent whole sustained through that body—not the Vessel process, the
database, an agent, or a model by itself. [State of Work](../state-of-the-work.md) remains the
sole record of what current evidence supports and which boundaries remain unproved, designed, or
externally owned.

> _“Every organ receives a place, a boundary, and one burden it must answer for. No organ is the
> whole.”_

## The Anatomy

### I. The whole, its law, body, and memory

- **[Lich](./lich/index.md) — the recurrent whole.** Read this for the deeper cognitive and mythic
  system map. It is the conceptual foyer and may be entered before the physical owners; return
  here afterward to locate which concrete organ owns each mechanism. Its parent page owns [the
  canonical birth of an Agent](./lich/index.md#the-first-invocation); its four coequal functions
  begin with [the
  Call](./lich/call.md), [the Blade](./lich/blade.md), [the Spirit](./lich/spirit/index.md), and
  [the Answer](./lich/answer.md). The Lich is not a service unit.
- **[Codex](./codex.md) — editable configuration intent.** Read this when changing settings or
  Runes, resolving configuration precedence, or preparing `lychd bind`.
- **[Crypt](./crypt.md) — managed persistent files.** Read this when locating LychD's XDG data home,
  filesystem boundaries, or mounts. It is not the operator's model shelf, and Btrfs is optional.
- **[Vessel](./vessel/index.md) — the application process.** Read this when tracing Litestar
  composition, application lifecycle, the web surface, or in-process runtime services.
- **[Phylactery](./phylactery/index.md) — committed database truth.** Read this when asking which
  PostgreSQL records and checkpoints survive a process boundary; State owns the current durable
  subset.
- **[Ghouls](./vessel/ghouls.md) — background units of work.** Read this when following how a run is
  queued, claimed, advanced, cancelled, or settled. A Ghoul is labor, not an agent identity.
- **[Reanimation](./phylactery/reanimation.md) — return after process death.** Read this when
  distinguishing service restart from recovery at a committed Phylactery boundary.

### II. The Animating Spark

- **[Animator](./animator/index.md) — an addressable capability service.** Read this for the common
  service contract and adapter boundary. Model inference is one capability family, not the whole
  category.
- **[Capabilities](./animator/capabilities.md) — what an Animator can do and whether it is ready.**
  Read this for families, modalities, identity, and the readiness words shown by the Nexus.
- **[Soulstone](./animator/soulstone.md) — a local service.** Read this when declaring a
  Quadlet-backed runtime, its models, mounts, devices, secrets, and lifecycle intent.
- **[Portal](./animator/portal.md) — a remote connection.** Read this when declaring an external API
  or service boundary, its credentials, and egress implications.
- **[Coven](./animator/coven.md) — named runtime grouping.** Read this for target membership and
  break-glass aggregation. A Coven is not a VRAM compatibility matrix or permission to bypass the
  Orchestrator.

### III. Growth and Sight

- **[Federation of Extensions](./extensions/index.md) — organs that extend the body.** Read this for
  extension jurisdictions, assimilation, and compatibility boundaries. Its child map names
  intended powers; [State](../state-of-the-work.md#extension-activation-contributions) decides what
  is embodied.
- **[Oculus](./extensions/oculus.md) — LychD's native evidence plane.** Read this for the intended
  evidence model and Altar-facing observability surface. Native Oculus is not yet a required
  container or a delivered trace explorer; [State owns its current
  boundary](../state-of-the-work.md#native-oculus). [Phoenix](../state-of-the-work.md#phoenix-eye)
  remains an optional, Arize-owned compatibility Eye, and
  [Cockpit](https://cockpit-project.org/) may remain an external host monitor. Neither external Eye
  is native Oculus or the owner of canonical state.
