# Local speech qualification

The first qualification uses one pinned audio.cpp runtime with Parakeet TDT 0.6B v3 for
transcription and Supertonic 3 for synthesis. Both upstream model profiles declare Slovak,
Czech and English. Declared support is not a LychD quality measurement.

An explicitly operated engineering probe may call a reviewed literal-loopback batch endpoint
with a pinned model profile. It does not issue an Animator grant, register Echo at normal boot,
or establish native Bridge audio admission. It must preserve those distinctions in its output.
No failed local attempt selects another runtime or a hosted service.

The next qualification candidate explicitly pairs whisper.cpp multilingual `small` transcription
with the existing audio.cpp Supertonic synthesis. A version 2 engineering profile binds each
operation independently to its literal-loopback endpoint, runtime revision, dialect, backend,
device and model pin. Version 1 audio.cpp profiles retain their existing schema and digest.
The whisper.cpp dialect requires an explicit declared input language and sends a transcription
request with JSON output; it does not send a misleading per-request model selector because that
server loads its weights at startup. Its observation retains the transcription binding's runtime
revision, while synthesis retains its own. This construction contract is not a Slovak quality
claim or a delivered native Echo provider.

The companion voice entry may remove only outer spaces, tabs and line endings when interpreting
a transcript as one strict instruction. It preserves the original attributed transcript; embedded
control characters and multiple instructions still refuse. This handles a server's text framing
without fuzzy correction of a misrecognized command.

## Probe contract

The operator supplies the endpoint, exact runtime revision, model digest and language declaration,
and an absolute private workspace outside every checkout. Input recording is an explicit bounded
operation; no background listening or wake phrase is admitted. Transcription accepts Echo's
canonical mono 16 kHz signed 16-bit WAV subset and verifies the exact source identity before
sending. The transcript remains an attributed interpretation with its source and selected model.
Language detection never authorizes translation or silently changes the requested output locale.

Synthesis accepts bounded text, one declared language and a stock voice, then retains bounded
validated WAV bytes with their digest. Cloning and reference voices are outside this probe.
Generation and playback are separate observations. No audio bytes enter logs or Graph state;
private artifacts and transcripts remain in the explicit workspace.

An optional Linux device helper records only after an explicit invocation, with a visible
capture indication, a fixed 1–15 second sample budget and a finite acquisition deadline after
process adoption. Launch adoption and required retirement can outlast that deadline. It requests mono
16 kHz signed 16-bit samples from the system ALSA `default` device and constructs a canonical
WAV. This respects the host's configured sound server, including PipeWire. A caller may explicitly
select the helper's `pulse` alternative when that ALSA PCM is installed; failure never changes
devices or retries capture. Device conversion is the capture backend's operation, not silent conversion
of an admitted artifact. A failed capture permits a fresh explicit gesture only after the helper
proves its recorder group retired; it never replays the failed occurrence. Unknown launch or
retirement keeps further audio closed. Cancellation, including cancellation during final
retirement, propagates only after joining the owned group; unproved retirement supersedes it
with an unsettled outcome.
No microphone qualification is inferred from tests using a substitute recorder.

The separate [Horizon voice entry](../../compositions/blockworld/horizon-assist.md#qualification)
can explicitly select finite local playback of its validated generated bytes after capture
closes. Its player process-group ownership, cancellation and failure are separate from synthesis.
A selected playback uses the system ALSA `default` output; only an explicit supported `pulse`
selection requests Pulse directly. Invalid devices refuse before launch, and a failed selection
never switches devices or retries. The helper forwards the exact inspected WAV bytes without
altering host routing or volume. Independently cancelled retirement is unknown ownership and
keeps later audio closed.
A successful player exit proves neither human hearing nor a native Echo playback receipt.
Ordinary speech-probe commands still only retain generated material.

Requests have finite transport and response bounds, no redirects, no ambient proxy or credentials,
and no automatic retries. Cancellation stops waiting locally; it must not claim the server's
inference stopped unless the exact dialect provides and proves that boundary. Hosted providers
require a separately admitted dialect, destination, credential, consent and cost bound.

## Acceptance

Qualify the exact binary/model pair with clean startup, readiness, a real synthesis and
transcription, bounded malformed-input refusal, cancellation and shutdown. Synthetic round trips
test transport and model execution, not microphone recognition or independent intelligibility.
The operator's bake includes Slovak and Czech diacritics, English game terms, player names,
coordinates, numbers, negation, background game sound and mixed-language utterances.

[Echo](echo.md) owns the speech lifecycle and [Audio](../../adr/37-audio.md) its law.
[State of Work](../../state-of-the-work.md#audio-admission) owns implementation evidence.
