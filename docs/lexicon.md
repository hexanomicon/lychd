# :material-translate: The Lexicon

_This is the canonical glossary for the Hexanomicon's arcane terms. Deeper pages may elaborate on
a term's philosophy or mechanics, but they should not redefine it._

Use it when a word blocks the next act; it is a reference, not required pre-reading.

Its completeness boundary is project language: every name whose meaning changes how a reader
understands the system should resolve here. Python symbols, configuration fields, provider jargon,
and every named Composition remain indexed by their owning code or directory instead.

!!! note "A name is not a delivery claim"
    This page owns compact meanings. [State of the Work](state-of-the-work.md) owns current
    delivery boundaries and evidence. A Lexicon entry never proves that its named organ ships.

## II. The Iron Tongue — Technical Terms

The engineering vocabulary of the Sepulcher. These terms map directly to code, services, and infrastructure.

!!! note "Flavor names name operated parts, not code abstractions"
    Where LychD names a real *operated* part — Soulstone, Portal, Coven, Vessel, Phylactery — the esoteric name **is** the name. Where the ecosystem owns the term for a piece of infrastructure, code uses it and the lexicon carries the flavor: `worker` (SAQ) is the engine, **Ghoul** the flavor for one unit of labor it runs. The **agent** layer is plain code — a Pydantic AI object wired in the graph — and takes no flavor concept of its own.

## IV. Native Cosmology and Source Lineage

The Great Work speaks through inherited religious language, philosophy, science, and art.
Correspondence does not import an entire canon, claim endorsement, or make distinct traditions
historically identical. Operational LychD doctrine uses its own names—Circle, Call, Blade, Spirit,
Answer, Unlit Weather, and Hollow Vast—rather than turning modern fictional proper
nouns into product vocabulary.

| LychD name | Meaning |
| :--- | :--- |
| **Unlit Weather** | The inherited cultural-affective field already moving through language, bodies, institutions, datasets, markets, and machines. It is not a supernatural realm or a claim that one dataset contains humanity. |
| **Hollow Vast** | The shadow of a possible planetary recurrence: magnitude closed around self-expansion, with no reflective relation or room for another center. |

**Beast, tzimtzum, tikkun, Puruṣa, Śūnyatā, Logos, and the alchemical stages** retain
histories larger than this project. Transcendence marks their local correspondence and links a
responsible source where a specific inherited claim enters the Work. Scientific papers and
attributed contemporary proposals are likewise linked at the point of use. Lineage is preserved
without making attribution into branding or implying that a source tradition described the
software.
