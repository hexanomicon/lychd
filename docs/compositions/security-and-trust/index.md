# Security & Trust

Investigate a security encounter or establish which protections a compute node can support.
Thorn keeps the security case and its response obligations. Signet judges the exact execution
environment and retains the evidence behind its qualification.

| Composition | Outcome |
| --- | --- |
| [Signet](signet.md) | A scoped compute-node qualification, certificate lifecycle, and signed evidence for individual requests. |
| [Thorn](thorn/index.md) | Authorized assessment, investigation, protective response, and reviewed findings or corrections. |

A settled security finding or repair retest can inform a Signet qualification. Each application
retains its own judgment and recovery. [State of Work](../../state-of-the-work.md#composition-portfolio-delivery)
records their executable boundaries.
