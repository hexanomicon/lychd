# Memory

Open **Memory** from Bridge or Séances to work with selected material and the configured
Archive. The same panel remains available across instruments. Opening it keeps the live
conversation, its draft and any pending judgment in place.

## Choose what you are working with

| Section | What it holds | What an action means |
| --- | --- | --- |
| **Working material** | Exact quotations and your notes, grouped by séance | Kept only in this open browser document; copy or export to keep it. |
| **Public notes** | The configured Archive's metadata and explicit management controls | Submit a public-note candidate, then separately review promotion, correction or revocation. |
| **Recall** | An explicit query over the configured public sources | Inspect attributed selected sources; this does not send an answer request. |

Working material and Archive records have separate lifetimes. Selecting a quotation does not
admit it as memory. A candidate is retained under its Archive profile; promotion makes it
eligible under current policy. Neither promotion nor a recall selection guarantees that a later
model request will receive it.

## Gather and keep a quotation

In a [séance](seances.md), select a retained turn, mark it as a topic, open question or selected
material, and add a note explaining why it matters. Memory shows the same collection from Bridge
or another instrument. Session and supplied Run references stay attached to the exact quotation.
Opening Memory does not switch the conversation selected in Bridge.

Choose **Open source séance** to read the session, **Inspect source** to check the exact quotation,
or **Run evidence** to open its Run in Orb when a usable Run identity was supplied. An absent
or changed quotation stays as captured. A current access refusal clears protected material.

The collection shares Séances' document-local limits. Export before closing or reloading the
document; the exit warning does not save the material. No quotation, note or query is written to
localStorage. Private conversation material is not automatically copied into the public intake
form, declassified or admitted to Archive.

## Manage admitted public material

**Public notes** uses the existing [public-note management procedure](bridge.md#manage-public-notes).
Begin a new note explicitly with public source material. Intake and promotion remain separate;
correction needs complete replacement text under a new revision. Metadata inspection does not
retrieve a note body or prefill an edit. Review revocation's consequences before submitting it.

The legacy `/bridge?notes=manage`, `new`, `recall` and exact-record links enter this same surface.
Closing the panel or switching instruments keeps initialized management and recall sections alive
for the browser document. It does not cancel an operation, resubmit a write, or turn an unknown
result into a failure. Use the existing explicit Check/recovery controls after a lost response.
Current refusal clears the protected projection through its owning controller.

## Recall and inspect evidence

Recall remains a separately admitted, explicit source query with its own profile, threshold,
generation and current-access requirements. Follow [Recall public sources](bridge.md#recall-semantic-sources)
for its preparation and recovery boundaries. Opening the section performs no automatic query.

For an existing answer Run, [Orb's Archive-selection inspector](orb.md#inspect-a-matching-archive-selection)
can expose its bounded text-free receipt. That historical selection is not a complete Context,
proof of consumption or proof of provider transmission.

Archive owns admission, lifecycle and Recall. Context owns what can enter an Invocation.
The current panel covers temporary quotations and the configured public Archive profile.
The [Atlas memory map](atlas.md#the-shared-memory-map) describes future saved and curated knowledge
with source provenance. Model training and general Persona authoring remain separate work.
