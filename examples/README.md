# LychD Examples

These examples are not loaded by LychD automatically. They are copy/edit
starting points for a Codex under `~/.config/lychd/`.

## Groups

- `runes/`: raw Codex mirror snippets grouped by Rune anchor.
- `profiles/`: copyable operator profiles grouped by deployment shape.
- `llamacpp/`: support files for llama.cpp examples, such as router presets.

Start with a profile when you want a working machine shape. Use raw runes when
you only need one declaration to paste into an existing Codex.
