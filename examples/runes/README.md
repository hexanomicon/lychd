# Rune Snippets

This tree mirrors the Codex Rune root: `~/.config/lychd/runes/`.

Use these building blocks only when you already have a Codex and want to copy
one Rune into its matching anchor.

- `animator/portals/`: remote/API-backed Animator Runes.
- `animator/soulstones/`: local/container-backed Animator Runes.

For a machine-shaped example, use `../profiles/`.
