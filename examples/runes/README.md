# Rune Snippets

This tree mirrors the Codex rune root, `~/.config/lychd/runes/`.

Files here are individual building blocks. They are useful when you already
have a Codex and want to copy one Rune into the matching anchor.

- `animator/portals/`: remote/API-backed Animator Runes.
- `animator/soulstones/`: local/container-backed Animator Runes.

For complete machine-shaped examples, use `../profiles/` instead.
