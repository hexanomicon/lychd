# Operator Profiles

Profiles are copyable example Codex fragments for common hardware shapes.

The folder names describe capacity classes, not exact product requirements:

- `nvidia-24gb/`: one 24 GB NVIDIA card, such as RTX 3090, RTX 4090, A5000.
- `nvidia-2x24gb/`: two 24 GB NVIDIA cards, commonly dual RTX 3090.

Keep exact model paths, ports, and mount locations local to your machine. The
profile documents the intended runtime pattern and the fields to edit.
