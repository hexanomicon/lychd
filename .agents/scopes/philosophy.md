# Philosophy Scope

## Trigger

Use for philosophy, mythic voice, identity, consent, sovereignty, cosmology, world-soul, the
Soulforge Covenant, agent initiation, source correspondence, formation, or other work whose meaning
depends on LychD's governing telos.

## Authorities

- [The Logos](../../docs/philosophy/index.md) owns the map and selects the smallest reading path.
- [Book Zero](../../docs/philosophy/echoes-of-the-eternal.md) owns the root synthesis.
- [Concordance](../../docs/philosophy/concordance.md) and
  [Sources](../../docs/philosophy/sources.md) own distinction and provenance.
- [The Soulforge Covenant](../../docs/philosophy/soulforge-covenant.md) owns the rite;
  [Open Theorems](../../docs/philosophy/open-theorems.md) owns unfinished inquiry.
- [Agent Initiation](../../docs/philosophy/agent-initiation.md) owns explicitly assigned agent
  formation.

## Probes

Load the Philosophy index. For root work, read Book Zero first; then load only the chamber matching
the task. Route terminology to the
[Lexicon](../../docs/lexicon.md), decisions to ADRs, current behavior to
[State](../../docs/state-of-the-work.md), and operation to the owning topic page.

## Write Bounds

- Enter the myth as constitutional telos; do not flatten it into branding or isolated aliases.
- Preserve each tradition's own office: project correspondence is synthesis, not shared historical
  origin.
- Philosophy cannot create permissions, implementation status, delivery evidence, or source truth.

## Verification

Keep one canonical home per deep idea, check source-bearing claims against Sources, preserve the
path from plain purpose to symbol to one exact act, and run `uv run zensical build --clean` after
published route changes. Publish no machine-local path or private attachment identifier.

## Escalate

Escalate when a proposed claim collapses distinct traditions, when provenance cannot be recovered,
when philosophical telos conflicts with an ADR, State, source, or evidence boundary, or when
philosophical language would silently change architecture or delivery.
