# Companion Android Client

This is the reserved Android client project for the [Companion Composition](../../docs/compositions/companion/index.md).
When implementation begins, Gradle project files belong here and the application module keeps
Android's native `app/src/main/` source layout. The intended client shape is native Kotlin with
Jetpack Compose; this marker does not claim that an Android client is implemented or delivered.

See [ADR 01](../../docs/adr/01-doctrine.md#repository-source-topology) for the client boundary.
